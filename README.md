# 🛒 E-commerce Customer Data Science

End-to-end e-commerce customer analytics and purchase prediction project using Python and Machine Learning.

## 📌 Project Overview

This project analyzes customer purchasing behavior in an e-commerce environment and identifies the key factors influencing purchase decisions.

The project covers data preprocessing, exploratory data analysis, feature engineering, statistical analysis, machine learning model development, and business recommendations.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify factors influencing purchase decisions
- Explore customer engagement and purchasing patterns
- Build a machine learning model to predict purchase status
- Generate actionable business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Google Colab

## 🔍 Project Workflow

1. Data Loading & Understanding
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Correlation & Statistical Analysis
6. Machine Learning Model Development
7. Model Evaluation
8. Business Insights & Recommendations

## 🤖 Machine Learning Models

### Logistic Regression
- Accuracy: **74.89%**

### Random Forest
- Accuracy: **74.40%**

Logistic Regression achieved the best performance among the evaluated models.

## 📊 Key Findings

- Purchase Frequency was the strongest predictor of purchase behavior.
- Customers with more previous purchases were more likely to purchase again.
- Recent purchasing activity showed a positive relationship with purchase probability.
- Website engagement showed a positive association with purchase behavior.
- Loyalty program membership showed a positive association with purchase behavior.

## 💡 Business Recommendations

- Target frequent purchasers with personalized offers.
- Implement re-engagement campaigns for inactive customers.
- Reward repeat customers through loyalty benefits and exclusive offers.
- Improve website engagement using personalized recommendations and promotions.
- Use the predictive model to identify customers with a higher probability of purchase.
- Regularly monitor model performance and retrain when new customer data becomes available.
